# Drizziq 1.3.0 screenshots

Raw 1080 × 2160 PNG captures from the connected OnePlus 5T (`ONEPLUS A5010`),
Android 13 / API 33, on 2026-10-31. Installed app version: 1.3.0, versionCode 4;
the phone uses its existing development signing key with the released source.

The captures use the public Munich preset and actual DWD weather/radar data.
The Places capture uses an empty demonstration favourites list. Original saved
places, favourites and radar-camera preferences are restored byte-for-byte after
capture. Images are not cropped, recoloured or otherwise edited.

The same Today/Radar images appear in the repository README; all four views are
attached to and embedded in the Codeberg v1.3.0 release. The existing release tag,
APK and checksum are retained for this screenshot-only correction.
